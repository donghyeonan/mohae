# Behaviors

- Time 0: all five fields use the warm off-white surface.
- Pointer moves across the first three fields in sequence.
- Hover state: the field background image fades in over roughly 300–450ms; the label remains centered and changes to a light tone over imagery.
- Leaving a field fades it back to the off-white plane.
- Only one field is active at a time.
- Click behavior is not shown. The clone uses click to pin the same state for touch and keyboard access.
- Focus mirrors hover. Escape clears a pinned state.
- Desktop is source-observed. Tablet and mobile behavior are inferred: the five fields become equal horizontal rows because the supplied video contains no responsive reference.
- Reduced-motion mode removes the fade duration.
