# Dependency graph

- `index.html` owns the five fields, Life Lab text, and semantic detail content.
- `styles.css` owns the fixed five-column layout, source-frame backgrounds, fade, responsive rows, focus states, and reduced motion.
- `app.js` owns one active/pinned field, Escape clearing, and current-field meta text.
- `server.mjs` is a Node standard-library static server.
- No third-party runtime library, canvas, Lottie, WebGL, or build step is required.
